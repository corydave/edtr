    IMGEDTR is a lightweight image editor for marking up screenshots and photos.

    Private by design. Your images never leave this device. There are no uploads, accounts or analytics, and the page's security policy blocks it from sending data anywhere.

    The only outside code is the HEIC converter (libheif, via the heic-to library), downloaded once from jsDelivr the first time you open an iPhone photo, checked against a fixed fingerprint, then kept for offline use.

    Projects. Save project keeps everything editable in an .imgedtr file. A project also keeps the original pixels under any Redact box, so share exported images, not project files.

    Part of a family of browser tools that all work this way - see More apps.
