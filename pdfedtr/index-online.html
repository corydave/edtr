PDFEDTR edits PDFs entirely in your browser: add text, sticky notes, dates, highlights, shapes, form fields and signatures, and reorder, add or delete pages.

Private by design. The PDF you open is read into this tab and never uploaded. There is no server, no account and no analytics. Downloading writes the edited file straight to your computer.

Outside code. PDFEDTR uses two libraries: pdf.js (to draw pages) and pdf-lib (to write the edited file). The version on pdfedtr.app has both built into the one file, so it needs no network once it has loaded, and it works when saved to a computer and opened from there. The page's security rules stop it from sending anything anywhere.

Part of a family of browser tools that all work this way - see More apps.

Settings

Page width fills the window on a phone, without making the page huge on a big screen.

While you move things, they line up with the page's edges and middle and with each other, and a guide line shows the match. Hold Alt (Option on a Mac) while dragging to move freely.

On: after you place a red X, a checkmark, a highlight, a shape or a form field, the same tool stays ready for the next one - handy for marking a whole page. Off: PDFEDTR goes back to Select, so you can adjust what you just placed.
