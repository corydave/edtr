Font size and zoom are the same setting, so Ctrl with plus or minus moves this too. Tab size sets both how wide a tab character renders and how many spaces the Tab key inserts.

Version

A text editor that is one HTML file. No build step, no framework and no dependencies - the whole thing is a transparent text box laid over a syntax-colored copy of the same text, with a gutter that measures itself against the wrapped lines.

Highlights HTML, CSS, JavaScript, Java, JSON, Python, Markdown, SQL, shell, XML and YAML.

Served over HTTPS it can be installed as a standalone app, registered as the opener for the file types it understands, and opened with no network at all.
